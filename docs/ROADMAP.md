## 建议分工与顺序

1. 项目负责人确定业务口径、老师对齐、现场输入、里程碑和合并决策。
2. 师弟先领取“独立复现”和“页面验收”，用一项小任务跑通分支与 PR 流程。
3. 双方共同检查结果、复核样本；明确任务后再分配具体规则或平台模块。
4. 顺序：代码导入 → 第二台电脑复现 → 新版页面验收；业务口径与现场协调可同步推进，再开展 A3/A4/A5。
