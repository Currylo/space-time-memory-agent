## 当前保守忽略策略

初始 .gitignore 排除 data/、demo/data/、demo/media/、runs/、upstream/ 与运行目录。其目的是避免首次导入夹带未审查资产，不代表这些目录里所有内容都不需要版本管理。

导入时识别必需的小型配置、来源登记、样例 JSON 和测试夹具，将安全且许可明确的内容移入专用样例目录，或添加精确的白名单。不得为了让页面运行而直接取消整个数据目录的忽略规则。

reports/ 默认只放行 Markdown 总结。此规则仅按文件类型筛选，仍需人工检查说明里是否包含内部地址或个人信息。
