## 首个里程碑

让第二位开发者在另一台电脑上，按文档获取代码、依赖及合法可用的样例数据，启动同一演示页并完成最小验收。这个里程碑优先于新增规则或语义功能。

建议以本地 `st_memory_experiments/` 的**内容**作为仓库根目录，保留 `src/`、`scripts/`、`tests/`、`demo/` 等相对路径。源码导入前需核对真实目录和依赖文件，避免移动后破坏路径。

源码和必需媒体准备好后，现有页面的启动方式为：

```bash
python3 demo/serve.py --port 8765
```

浏览器访问 `http://127.0.0.1:8765/showcase.html`。这条命令当前不能在仅有协作文档的仓库中运行。

## 上传范围

代码、依赖清单、配置模板、测试、说明和经检查的小型样例数据纳入 Git。原视频、录像、模型、虚拟环境、运行日志、真实复核数据库和密钥不随首次提交上传。

本仓库当前为 **公开仓库**。现场视频、人工复核记录、内部地址和第三方资产需在分享范围与许可明确后另行管理。第三方代码和资产保留原许可证与来源；暂不替整个项目声明新的开源许可证。

## 开发流程

`领取 Issue → 从最新 main 开任务分支 → 提交改动与验证结果 → 创建 Pull Request → 检查后合并`。

每个人使用自己的克隆目录。建议由项目负责人确认业务口径、协调现场输入并合并 PR；师弟先完成独立复现与验收，再逐项承担页面或规则任务。
